# Project Overview

This project analyzes the evolution of Netflix content using a structured,
analytics‑engineering‑style workflow. The goal is to understand how Netflix’s
catalog has changed over time, what made the 1990s unique, and how genres,
durations, and countries have contributed to the platform’s growth.

The project is organized into three main notebooks:

1. **Notebook 1 — Data Cleaning & Preparation**  
   Loads the raw dataset, applies a full cleaning pipeline, and exports a
   clean, analysis‑ready file.

2. **Notebook 2 — 1990s Movies Deep Dive**  
   Focuses on movies released between 1990 and 1999, exploring genre patterns,
   duration trends, country contributions, and director frequency. Includes
   comparisons between 1990s movies and all other movies.

3. **Notebook 3 — Global Trends & Evolution**  
   Zooms out to analyze the entire Netflix catalog, covering content growth,
   genre evolution, duration trends, country diversity, and the rise of TV shows.

The project uses modular Python scripts for cleaning, EDA, and visualization to
keep the notebooks clean and reusable.
